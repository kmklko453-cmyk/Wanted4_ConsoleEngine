# Ownership Logic 상세 설명 (추가된 코드 기준)

아래 설명은 이번에 **추가/수정된 코드 블록**만을 대상으로 한다. 기존 코드 기능은 제외했다.

## 1) Ball 소유권/접촉 처리

### 파일
- `Game/Actor/Ball.h`
- `Game/Actor/Ball.cpp`

### 추가된 멤버/함수
- `Actor* ownerActor`
  - 공의 현재 소유자. 공이 멈춰 있을 때 소유자의 위치에 공을 붙여 그린다.
- `PlayerBase* lastPlayer`
  - 마지막으로 패스/슛한 플레이어. 패스 성공 시 자리 교체를 위해 사용.
- `void ResolveContactOwnership()`
  - 공이 플레이어나 팀원과 닿았는지 검사하고, 닿았으면 소유권을 갱신하는 함수.

### 동작 의도
- 공이 **플레이어에 닿으면** 그 플레이어가 소유권을 획득한다.
- 공이 **팀원에 닿으면** 해당 팀원의 팀 컬러를 가진 플레이어가 소유권을 획득한다.
- 접촉 시 비행 상태를 해제하고 `targetPos`를 초기화해 즉시 소유자에 붙는다.

### 구현 포인트
- `ResolveContactOwnership()`에서 **현재 소유자(ownerActor)**와의 접촉은 무시한다.
- 접촉 즉시 `SetOwner(...)`, `SetLastPlayer(...)`를 호출하고, 비행을 종료한다.


## 2) Ball::Tick 변경점

### 추가된 로직
- **초기 소유자 설정**
  - `ownerActor`가 없으면 레벨의 첫 번째 플레이어를 소유자로 설정.
  - 공이 게임 시작 시 누구에게 붙을지 결정.

- **비행 중이 아닐 때 접촉 검사**
  - 공이 소유자 위치에 붙어 있어도 상대가 닿을 수 있으므로 `ResolveContactOwnership()` 실행.

- **도착 순간 접촉 처리**
  - 목표 위치에 도착하는 순간에도 `ResolveContactOwnership()`를 호출하여 소유권 변경 누락을 방지.

### 요약
- 공이 이동 중이든, 멈춰 있든 **항상 접촉 시 소유권이 바뀌도록** 보장하는 목적.


## 3) ChangePosition 교체 로직

### 파일
- `Game/Level/SokobanLevel.cpp`

### 추가/수정된 로직
- **같은 팀 패스 성공 시 자리 교체**
  - `lastPlayer`와 닿은 팀원의 위치를 **서로 스왑**한다.
  - 스왑 후에도 공 소유권은 `lastPlayer` 유지.

- **상대 팀원 접촉 시 공수 전환**
  - 닿은 팀원의 팀 컬러와 같은 플레이어를 찾는다.
  - 그 플레이어와 팀원을 스왑한 뒤, 소유권을 해당 플레이어로 변경.

### 요약
- 패스 성공 시: **플레이어 ↔ 팀원 자리 교체**
- 상대 팀원 접촉 시: **상대 플레이어 ↔ 팀원 자리 교체 + 소유권 변경**
- 플레이어끼리는 자리 교체 없이 소유권만 변경


## 4) PlayerBase 패스/슛 제한

### 파일
- `Game/Actor/PlayerBase.cpp`

### 추가된 체크
- `IsOwnedBy(this)`
  - 공 소유자가 아닐 경우 패스/슛 동작을 막는다.

### 의미
- 공이 없는 플레이어는 패스/슛 불가.
- 소유권 기반으로 공격 턴을 제한하는 역할.
